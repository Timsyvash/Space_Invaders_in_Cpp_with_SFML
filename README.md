# 👾 Space Invaders (SFML & C++)

Класична аркадна гра **Space Invaders**, реалізована мовою **C++** з використанням графічної бібліотеки **SFML (Simple and Fast Multimedia Library)**. 

У цій грі гравець керує космічним кораблем, захищаючи Землю від хвиль ворожих прибульців, які рухаються сіткою та маневрують з боку в бік, поступово опускаючись усе нижче.

---

## 🎮 Особливості гри

* **Сітка ворогів:** Вороги сформовані у динамічну сітку ($4 \times 8$), яка переміщується екраном і змінює напрямок при досягненні меж екрана.
* **Стрільба та колізії:** Реалізована обробка пострілів гравця та ворогів, а також можливість **збивати ворожі лазери у повітрі**.
* **Пауза та Перезапуск:** Можливість поставити гру на паузу або швидкого перезапуску після поразки.
* **Графічні оверлеї:** Індикація станів **PAUSED** та **GAME OVER** поверх ігрового поля.

---

## 🕹️ Управління (Controls)

| Клавіша | Дія |
| :--- | :--- |
| **`A`** / **`←` (Вліво)** | Рух корабля ліворуч |
| **`D`** / **`→` (Вправо)** | Рух корабля праворуч |
| **`Space` (Пробіл)** | Постріл лазером |
| **`P`** | Пауза / Зняти з паузи |
| **`R`** | Перезапуск гри (після Game Over) |

---

## 🛠️ Технології

* **Мова програмування:** C++11 або новіше
* **Графічна бібліотека:** SFML 2.5 / 2.6
* **Компілятор:** MSVC (Visual Studio) / GCC / Clang
